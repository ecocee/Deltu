# UI Context

Deltu does not require or include a graphical UI.

Deltu is a **developer-first CLI-based engine**. Developers interact with it through the CLI, configuration files, APIs, SDKs, logs, and metrics.

The CLI should provide a simple developer experience similar to tools such as Docker Compose:

```bash
deltu up
deltu down
deltu run
deltu check
deltu status
deltu health
deltu logs
deltu config
```

No dashboard, frontend, web UI, design system, or visual interface is required for the core project.

> **CLI first. API first. Developer first.**
